## 1. 强约束（铁律，违反即返工）

1. 只发夸克网盘，不发百度和其他盘，无需快递、无需发货
2. 标题、图文、文案一律不写价钱；闲鱼发布时价格字段填 1 元
3. 文案删除“图1图2见图”“试看片段私聊”这类描述
4. 一键复制文案 = 商品简单介绍 +【说明】只发夸克网盘，不含链接、价钱和写给自己看的描述；直接贴聊天即可复制，不用打开文件
5. 夸克分享单独 3 行：文件夹名、链接、提取码；分享要求不限时、需提取码、带文件名
6. 落盘 `D:\闲鱼\<项目>\` 扁平单目录：`01-04.png` + `desc.txt` + `闲鱼发布文案_直接复制.txt`，不套娃、无重复文件
7. 自动发布不可用就手动发布：`https://www.goofish.com/publish`，用户自己传图、填价、贴文案，不代点提交
8. `https://44.81938193.xyz/` 只发链接给用户手动打开，不自动打开

## 2. 标准流水线（7 步）

1. 收料：用户给教程名 + 集数 + 截图，确认 M 盘货源目录与集数
2. 写文案：按第 3 节写标题和 desc，一键复制先行
3. 做图：按第 4 节做 1080x1080 共 4 张，顺序 01 到 04
4. 校验：逐张看图，查文字出框、错字、徽章截断、顺序
5. 落盘：按第 5 节写入 `D:\闲鱼` 对应项目目录
6. 手动发布：图文完成后给用户发闲鱼发布页链接，用户自己操作
7. 归档推送：清理截图垃圾，按第 8 节提交推送

## 3. 文案规范

标题公式：`<教程原话> <集数> 只发夸克`（不写价）

`desc.txt` 结构：标题行、正文简介（分模块列集数分布）、适合人群一句、【说明】虚拟资料只发夸克网盘。`闲鱼发布文案_直接复制.txt` 与 `desc.txt` 同内容，聊天直接粘贴。

## 4. 图片规范

- 尺寸 1080x1080，每项目 4 张：01 封面 / 02 目录 / 03 收获人群 / 04 购买指南，无需实拍图
- 设计语言（Codex55 已验证）：白底蓝框 `BORDER 38 / BLUE #2F5DFF / DARK #1E293B / 灰卡 #F1F5F9`，圆角 32
- 字体：`C:\Windows\Fonts\msyh.ttc`（正文）/ `msyhbd.ttc`（加粗），标题 66pt、副标题 36pt
- 封面用 PIL 重渲
- 校验清单：文字无出框、徽章无截断（徽章宽按 `textlength + padding` 动态算）、中部卡片与标题无重叠（`card_y = y0 + 150`）、`Select-String 1元 0命中`

## 7. exec 与环境坑位

1. `workdir` 填真实存在目录（如 `C:/Users/1`），否则报“目录名称无效”
2. 命令文本不出现美元符开头词，不用 PowerShell 变量；写文件用 `Set-Content ... @' '@` here-string
3. 中文路径用正斜杠；写中文文件用 python `open(..., encoding="utf-8")`，不用 heredoc 拼换行
4. 超 10 秒转后台，发布类加日志重定向再分段看日志
5. 推送走代理（见第 8 节），推完保留代理配置（本机常驻，无需 unset）
